# KIS Trading LAB — 데이터에서 모의주문까지, 하나의 검증 흐름

발표일: 2026-09-09 · 검증일: 2026-09-08

## 발표 첫 문장
“KIS Trading LAB은 시세를 보는 데서 끝나지 않고, 전략 근거를 확인하고 과거 데이터로 검증한 뒤 한국투자증권 모의투자 주문까지 연결하는 트레이딩 실험 플랫폼입니다.”

## 장표에 넣을 핵심 기능
| 기능 | 강조 문구 | 구현 근거 |
|---|---|---|
| 통합 트레이딩 화면 | 계좌·관심종목·차트·주문을 한 화면에서 | 잔고/보유종목, 종목 검색, 100일 캔들, VTS 주문 입력 |
| 설명 가능한 전략 | 매수·매도 판단에 근거를 붙이다 | SMA5/20 교차, RSI14, 거래량 비율, 규칙별 충족 여부 API |
| 백테스트 | 수익률과 낙폭을 함께 검증하다 | T일까지의 지표로 신호 계산, 다음 봉 시가 체결, 수익률·MDD·거래수 |
| 운영센터 | 수집 → 분석 → 백테스트를 연결하다 | 통합 파이프라인, 대상종목/위험 한도, 실행 이력, 로그 |
| 주문 생명주기 | 주문 전송 이후의 상태까지 추적하다 | VTS 주문·조회·취소·체결 이력·정합성 대조 API, 중복 요청 방지 |

## 3분 시연 순서
1. 대시보드: 모의계좌 잔고와 보유종목을 보여준다.
2. 관심종목 선택: 일봉 차트, 이동평균, RSI와 전략 신호를 설명한다.
3. 운영센터 퀀트분석: 시그널과 백테스트 수익률·MDD를 함께 보여준다.
4. 시스템관리: 실행 이력과 VTS 전용 주문 안전장치를 설명한다.
5. 마무리: “조회, 판단, 검증, 모의 실행과 운영 기록이 하나로 이어집니다.”

## 설명 범위
- 후보 생성은 DRY RUN이며 자동 주문을 전송하지 않는다. 대시보드의 VTS 주문 버튼은 확인 후 모의투자 서버로 전송한다.
- 스케줄은 저장 기능이며 현재 배치는 수동 실행이다. 무인 자동매매가 완성됐다고 표현하지 않는다.
- 주문 취소·체결 동기화·정합성 대조는 API 기능이다. 모든 기능이 화면 버튼으로 제공되는 것은 아니다.
- 백테스트는 과거 데이터 기반 시뮬레이션이며 수수료·슬리피지 등의 실제 거래 차이를 반영한 수익 보장 자료가 아니다.
- WebSocket 구독/재연결 기능은 구현돼 있다. 이번 검증은 장외 시간으로 실시간 체결 틱 수신을 확인하지 않았다.

## 검증 결과
- 자동 테스트: 120개 통과. FastAPI/Starlette의 httpx 사용 중단 예정 경고 1개.
- Edge 브라우저: 운영센터 5개 메뉴, 설정 저장, 검색, 매수/매도 탭, 보유/주문 탭, 잘못된 수량 검증 확인.
- 실제 KIS 모의계좌 잔고 및 종목 시세 조회, 100일 차트·지표 표시 확인.
- 데스크톱 1600×1000, 모바일 390×844에서 페이지 가로 넘침 없음. JavaScript 예외 0건.
- 이번 점검에서 외부 모의주문 신규 전송·취소는 실행하지 않았다. 관련 로직은 자동 테스트로 검증했다.
- 수정: 기본 Cron 스케줄을 API가 거부하던 문제, 검증 오류가 [object Object]로 표시되던 문제, 브라우저 이탈 시 WebSocket 하위 작업이 남던 문제.
